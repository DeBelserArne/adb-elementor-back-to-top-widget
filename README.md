# Elementor Back to Top Widget

A WordPress plugin that adds a highly customizable "Back to Top" button widget for Elementor page builder.

## Features

- Multiple button types:

  - Icon only
  - Text only
  - Icon & Text combined

- Flexible positioning:

  - Bottom Right (default)
  - Bottom Left
  - Bottom Center
  - Top Right
  - Top Left
  - Top Center

- Full scrolling control:

  - Custom scroll offset to show/hide
  - Optional scroll percentage display
  - Configurable percentage position and symbol

- Extensive styling options:

  - Custom colors for icon and text
  - Background colors and gradients
  - Border customization
  - Box shadow effects
  - Typography settings
  - Custom padding and margin
  - Responsive controls for all devices

- Animation features:
  - Built-in Elementor animations
  - Custom hover animations
  - Configurable animation duration
  - Multiple timing functions

## Installation

1. Upload the plugin files to the `/wp-content/plugins/adb-elementor-back-to-top-widget` directory, or install the plugin through the WordPress plugins screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. The widget will be available in the Elementor editor under the "ADB Widgets" category.

## Usage

1. Edit a page with Elementor
2. Look for "Back To Top" in the elements panel
3. Drag and drop the widget onto your page
4. Customize the appearance and behavior using the various controls in the widget panel

## Requirements

- WordPress 5.0 or higher
- Elementor 3.0 or higher
- PHP 7.0 or higher
